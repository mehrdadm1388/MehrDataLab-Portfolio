========================================

Files:
1. sales_raw.csv

     and a duplicate row.
2. customers_raw.csv
   - Intentionally contains whitespace, a missing age, and a duplicate row.

   - Example configuration for the classmethod/from_dict factory.

- cleaned_sales_raw.csv
- cleaned_customers_raw.csv
- cleaned_marriage_divorce_eda.csv
- etl_quality_report.csv
